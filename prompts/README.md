# NEXUS Prompt Workspace

This folder is the source-of-truth prompt set for SIH26152.

## Files

- `MASTER_SUPER_ULTRA_BUILD_PROMPT.md` — complete problem, architecture, connector policy, analytics, UI, testing, demo, security and definition-of-done specification.

## Rule

Builds must preserve the official five SIH26152 requirements:

1. Continuous multi-platform collection + chronology
2. Multi-dimensional sentiment/emotion
3. Aggregate anonymized demographics
4. Real-time trend/topic detection
5. Link/network analysis

Every feature must be evidence-backed. Replay data must never be presented as live data.
